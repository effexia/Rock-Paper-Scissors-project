# Rock-paper-scissors

A browser game of Rock Paper Scissors against the computer, built as part of [The Odin Project](https://www.theodinproject.com/) Foundations course. The game runs entirely through browser dialogs and has no GUI yet.

## How to Play

1. Open `index.html` in your browser.
2. Type `rock`, `paper` or `scissors` into the prompt. Input is case-insensitive, so `ROCK` or `RoCk` also work.
3. Play 5 rounds against the computer.
4. The final score and the winner are shown at the end.

## Built With

- HTML5
- JavaScript (ES6)

## What I Learned

- Planning a solution with pseudocode before writing code
- Breaking a problem into small functions with one job each
- Generating random choices with `Math.random()` and `Math.floor()`
- Using conditionals and the ternary operator to decide the round winner
- Getting user input with `prompt()` and normalizing it with `toLowerCase()`
- Tracking score with variables and understanding function scope
- Repeating rounds with a `for` loop
- Building messages with template literals
- Committing changes regularly with Git
